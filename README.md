## Medical Chatbot

This project is a medical chatbot with a Java backend and a Python machine learning service.

## Running with Docker

This project can be run using Docker and Docker Compose.

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose V2](https://docs.docker.com/compose/install/)

### Building and Running

1. Clone the repository.
2. Navigate to the project root directory.
3. Run the following command to build the Docker images and start the application:

   ```bash
   docker compose up --build
   ```

4. The application will be available at `http://localhost`.
